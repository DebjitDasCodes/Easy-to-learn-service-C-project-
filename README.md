Programming is often taught strictly as a science, but I view it through the lens of a medium—much like a canvas or an instrument. To me, writing software is an act of digital craftsmanship:

* **The Science:** Clean architecture, optimized algorithms, robust data structures, and rigorous problem-solving.
* **The Art:** Elegant syntax, thoughtful abstractions, intuitive user experiences, and the sheer joy of transforming abstract ideas into functioning reality.

Every script and module in this repository reflects an eagerness to dive deeper into the computational stack, tackle sophisticated challenges, and embrace the beauty of complex topics.
